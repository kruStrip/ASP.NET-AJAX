# ASP.NET: практикум

Практические работы по ASP.NET — от AJAX-запросов до приложений с авторизацией и мониторингом.

**Стек:** C# · ASP.NET · AJAX · .NET

## Что внутри

- `TaskBoard/` — доска задач
- `SecureTodo/` — задачи с авторизацией
- `LiveMonitor/` — мониторинг в реальном времени
- `DashboardAdmin/` — админ-панель
- `4_курс/` — работы курса

## Запуск

Открыть решение в Visual Studio и запустить нужный проект.
