МузЛото — этап 5: сотрудники и назначения

1. Остановите локальное приложение Ctrl+C.
2. Из корня ~/ASP.NET-AJAX распакуйте архив:
   unzip -o ~/Downloads/MuzLoto_stage5_staff_management.zip
3. Зафиксируйте изменения (не добавляйте .env):
   git add 4_курс/Разработка_веб_приложений_ASP.NET_AJAX/Итоговый_проект/проект/
   git commit -m "feat(muzloto): manage staff roles and game assignments"
   git push origin main
4. Проверьте GitHub Actions, затем запустите приложение:
   cd 4_курс/Разработка_веб_приложений_ASP.NET_AJAX/Итоговый_проект/проект
   bash scripts/dev.sh
5. Откройте /staff (Admin), создайте тестового Manager.
   На /events назначьте Manager на конкретную игру и проверьте его доступ.

Изменения схемы PostgreSQL отсутствуют — новые миграции не нужны.
Ни пароли, ни .env, ни база в архив НЕ включены.
Сборка CI и пользовательское тестирование после публикации обязательны.
