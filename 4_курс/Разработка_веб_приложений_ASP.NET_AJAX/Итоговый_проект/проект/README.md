# МузЛото — итоговое приложение (каркас)

**Статус: проектирование, без кода полной реализации.**

Ожидаемый стек: ASP.NET Core, Razor Pages, AJAX (Fetch), REST API v1/v2, SignalR, EF Core, Identity, JWT, PostgreSQL.

- src/ — серверные модули и страницы;
- wwwroot/ — JS, CSS и клиентские ресурсы;
- tests/ — интеграционные и модульные тесты;
- docs/ — диаграммы, описание БД, контракт API.

Приложение не запускается до появления кода и конфигурации.
