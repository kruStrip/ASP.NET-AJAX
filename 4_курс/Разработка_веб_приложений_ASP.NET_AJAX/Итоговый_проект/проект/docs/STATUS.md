Через релей файл не загружается: провайдер пропускает к `*.workers.dev` тела только примерно до 10 КБ (замерено 2026-11-03: POST на 68 КБ висит, после ~10 КБ идут только ретрансмиты), поэтому сайт отправляет в `POST {релей}/send-file` маленький JSON с подписанной 30-дневной ссылкой `/receipts/{id}/{файл}?t=…`, а воркер сам скачивает файл с сайта (только https, хосты из `FILE_HOSTS`, по умолчанию `muzloto.b-o-c-a.ru`, до 20 МБ) и отдаёт его Telegram.
- [x] **С прод-сервера `api.telegram.org` недоступен** (провайдер блокирует Telegram: TCP-соединение по 443/80 висит до таймаута, при этом `api.wazzup24.com` работает).
