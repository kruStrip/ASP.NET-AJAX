# Подключение FormDesigner (вебхук)

Клиентская форма остаётся в FormDesigner (форма 246156). Заявки попадают в систему через модуль **WebHooks**:
FormDesigner отправляет поля формы на адрес приложения, приложение создаёт заявку «Ожидает подтверждения»
(места не занимаются), сотрудники видят её сразу (SignalR).

## 1. Что нужно заранее

- **Публичный HTTPS-адрес приложения.** FormDesigner работает в интернете и не достучится до `localhost`.
  Для проверки до развёртывания подойдёт туннель (например, `cloudflared tunnel --url http://localhost:5080`).
- **Секрет интеграции** — на рабочем сервере уже создан: `ssh boca 'grep INTEGRATION /home/BocA/muzloto/.env'`.
  Локально — `MUZLOTO_INTEGRATION_SECRET` в `.env`. Без секрета вебхук отвечает 503.
- Игры и даты в приложении должны совпадать с датами в форме (дата + время).

## 2. Основные параметры вебхука

| Поле | Значение |
|---|---|
| URL адрес | `https://muzloto.b-o-c-a.ru/api/integrations/formdesigner/webhook` |
| Метод передачи данных | любой из предложенных: POST (форма или JSON) или GET — приложение принимает все |
| Отправлять уведомление на почту при ошибках | **включить** — так вы узнаете, если заявка не принята |

## 3. «Параметры запроса из формы»

Нажмите «Добавить параметр из формы» для каждой строки. Имя параметра — **ровно** как в левой колонке.

| Имя параметра | Поле формы | Обязателен |
|---|---|---|
| `game_date` | «Выберите дату» (05.11.2026) | да |
| `game_time` | «Время игры» | желательно: нужен, если в один день несколько игр |
| `game_name` | «Название игры» | нет (уточняет, если игр в день несколько) |
| `quantity` | «Кол-во выбранных билетов» | да |
| `name` | «Введите ваше имя» | да |
| `phone` | «Введите ваш телефон» | да |
| `telegram` | «Введите ваш Telegram ник» | нет |
| `team` | «Введите название команды» | да |
| `total` | «Итого к оплате» | нет (сверяется с ценой, расхождение пишется в журнал) |
| `submission_id` | системное поле с номером/ID результата, **если есть в списке** | очень желательно |

## 4. «Произвольные параметры запроса»

| Имя | Значение |
|---|---|
| `key` | значение `MUZLOTO_INTEGRATION_SECRET` |

## 5. Как приложение обрабатывает вебхук

- Игра ищется по **местной** дате (и времени) сеанса; завершённые и архивные даты не принимают заявки.
- Цена берётся из приложения в момент заявки, а не из поля «Итого».
- Телефон приводится к виду `+7XXXXXXXXXX`, Telegram — к `@username`.
- **Повторная доставка не создаёт дубль:** по `submission_id`, а если его нет — по совпадению всех полей в течение часа.
- Заявку на больше билетов, чем осталось, **не отклоняем** (клиент уже видел «отправлено»): она ждёт сотрудника.
  Отклоняется только количество больше вместимости игры.

| Ответ | Когда | Что делать |
|---|---|---|
| 201 | заявка создана | — |
| 200 | повторная доставка той же заявки | — |
| 400 | не хватает параметра / неверная дата или количество | проверить имена параметров в настройках вебхука |
| 401 | неверный или отсутствует `key` | сверить секрет |
| 404 | на эту дату нет открытой игры | создать дату в приложении или проверить формат даты |
| 409 | продажи закрыты / несколько игр без времени / больше вместимости | передать `game_time`, открыть продажи |
| 503 | не задан секрет интеграции | задать `Integration__Secret` |

В журнал приложения пишутся **только имена** пришедших параметров (без персональных данных) — по ним видно,
правильно ли настроены названия.

## 6. Проверка после настройки

1. Отправьте тестовую заявку через форму с обезличенными данными.
2. Она должна появиться в «Нужно подтвердить» (у второго сотрудника — без перезагрузки).
3. Если не появилась — письмо об ошибке от FormDesigner и журнал приложения подскажут причину.

## 7. Что пока не сделано

- **Обновление дат и остатков в самой форме.** Списки дат и количества в форме сейчас ведутся в FormDesigner;
  программное изменение вариантов не проверено. Пока их правят вручную по «Оперативному отчёту» (`/reports`).
- **Уведомления сотрудникам** остаются прежними (FormDesigner); в приложении заявка появляется сразу.

Канонический JSON-маршрут `POST /api/integrations/formdesigner/submissions` (с ID сеанса и заголовком `X-Integration-Key`)
оставлен для доверенных адаптеров и тестов.
