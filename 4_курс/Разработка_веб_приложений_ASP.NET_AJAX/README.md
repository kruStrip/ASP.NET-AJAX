# Разработка веб-приложений ASP.NET / AJAX — 4 курс

Собрание учебных материалов по структуре задания преподавателя.

## Разделы

| Раздел | Практический проект |
|---|---|
| [Архитектура ASP.NET Core](Архитектура_ASP.Net_Core/) | TaskBoard — middleware, DI, MVC, маршрутизация, модель и JSON API |
| [Razor Views и клиентская часть](Razor_Views_и_клиентская_часть/) | ТЗ1: DashboardAdmin; ТЗ2: Bootstrap-каталог; ТЗ3: AJAX-каталог |
| [REST API в ASP.NET Core](Rest_API_в_ASP.NET_Core/) | TaskFlowApi — CRUD, DTO, EF Core, версионирование, Swagger |
| [SignalR и real-time](SignalR_и_real-time/) | LiveMonitor — хаб, группы, подписки, переподключение |
| [Безопасность](Безопасность_аутентификация_авторизация/) | SecureTodo — Identity, роли, JWT, авторизация по ресурсу, CSRF/XSS |
| [Итоговый проект](Итоговый_проект/) | «МузЛото» — техническое задание и каркас **без готовой реализации** |
| [Общие материалы](общие_материалы/) | Семь лекций, методические указания, ссылка на тест |

Оригинальные PDF, PPTX и DOCX прилагаются. Существующие учебные исходники из корневых папок копируются в требуемую структуру с помощью `setup_course_repo.sh` из корня Git-репозитория; старые папки сохраняются.

**Статус «МузЛото»**: описана архитектура и бизнес-правила, код итогового приложения пока не представлен. Это не завершённая реализация.
